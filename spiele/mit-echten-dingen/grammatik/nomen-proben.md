# Ist das ein Nomen? Zwei Proben

## Am Tisch: Der Merkzettel für morgen

Ihr braucht: einen Zettel und einen Stift

1. Einer sagt in zwei Wörtern, was morgen zu tun ist: „Brot holen“.
2. Prüft jedes Wort, bevor es auf den Zettel kommt.
3. Setzt ein, eine oder einen vor das Wort: „ein Brot holen“ klingt richtig, „Brot ein holen“ nicht.
4. Setzt zwei davor: „zwei Brote holen“ klingt richtig, „Brot zwei holen“ nicht.
5. Passt eine Probe, schreibt das Wort groß: Brot. Sonst klein: holen.
6. Dann ist der andere dran. Hängt den Zettel auf.

**Darauf kommt es an:** Passt ein, eine, einen oder zwei vor das Wort und die Zeile klingt noch richtig, ist es ein Nomen. Eine Probe reicht. Nomen schreibt man groß.

**Leichter:** nur Dinge, die ihr einpackt: „Mütze einpacken“. **Schwerer:** „Pause machen“: eine Pause machen, zwei Pausen machen.

## In Bewegung: Proben-Hüpfer

**Zum Verinnerlichen:** Spielt zuerst „Der Merkzettel für morgen“. Dieses Spiel hilft, die zwei Proben für Nomen zu behalten.

Ihr braucht: einen Flur oder freien Platz im Zimmer

1. Einer sagt eine Zeile aus zwei Wörtern: „Lampe anmachen“.
2. Probiert jedes Wort. Passt ein, eine oder einen davor, macht ihr einen Schritt nach vorn: „eine Lampe anmachen“.
3. Passt auch zwei, hüpft ihr danach zweimal: „zwei Lampen anmachen“.
4. Passt nichts, bleibt ihr stehen: „Lampe eine anmachen“.
5. Dann sagt der andere eine Zeile.

**Darauf kommt es an:** Passt ein, eine, einen oder zwei vor das Wort und die Zeile klingt noch richtig, ist es ein Nomen.

**Leichter:** nur Dinge, die ihr seht. **Schwerer:** „Idee haben“: eine Idee haben, zwei Ideen haben.
