# Die 3 in zwei Teile legen

## Am Tisch: Drei Löffel, zwei Teller

Ihr braucht: drei Löffel, zwei Teller

1. Legt alle drei Löffel auf einen Teller.
2. Schiebt einen Löffel auf den anderen Teller. Sagt, was ihr seht: „3 ist gleich 2 plus 1.“
3. Schiebt noch einen Löffel hinüber und sagt es wieder.
4. Macht weiter, bis alle drei Löffel auf dem anderen Teller liegen.

**Darauf kommt es an:** Es sind immer drei Löffel. Wandert einer hinüber, hat ein Teller einen weniger und der andere einen mehr. So findet ihr alle Arten, die 3 in zwei Teile zu legen. Auch ein leerer Teller gehört dazu: 3 ist gleich 3 plus 0.

**Leichter:** Nehmt nur zwei Löffel. **Schwerer:** Einer deckt einen Teller mit der Hand zu. Wie viele Löffel liegen darunter?

## Unterwegs: Drei Zapfen in zwei Händen

Ihr braucht: drei Blätter, Zapfen oder Stöckchen vom Weg

1. Sammelt unterwegs drei Dinge.
2. Einer von euch verteilt sie hinter dem Rücken auf beide Hände.
3. Eine Hand geht auf. Ihr seht zum Beispiel einen Zapfen.
4. Wie viele sind in der anderen Hand? Sagt es, dann geht auch sie auf.

**Darauf kommt es an:** Beide Hände zusammen haben immer drei. Wer eine Hand sieht, weiß, wie viele zur 3 noch fehlen.

**Leichter:** Nehmt nur zwei Dinge. **Schwerer:** Sagt ohne Dinge in der Hand alle Arten auf, wie drei auf zwei Hände passen.
