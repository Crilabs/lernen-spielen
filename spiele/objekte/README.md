# Gemeinsame Objekte

Hier liegen animierte SVG-Objekte, die mehrere Spiele nutzen (Tonne, Baum, Korb …). Objekte, die nur ein Spiel
braucht, liegen im Ordner dieses Spiels unter `objekte/` (siehe „Ablage“ in `docs/spielentwicklung.md`).
Der Bestand wird mit dem Objekt-Baustein (Aufgabe 5 des Prüfstand-Plans) gefüllt.
